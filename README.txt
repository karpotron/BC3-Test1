
BC3 Reader - Web PWA (fix)
==========================

Archivos incluidos:
- index.html
- app.js
- style.css
- manifest.json
- icon-192.png
- icon-512.png
- README.txt

Sigue las instrucciones del chat para subir a GitHub Pages:
1) Extrae el ZIP en tu PC.
2) Crea un repositorio en GitHub y sube todos los archivos a la rama 'main'.
3) En Settings -> Pages elige Branch 'main' y carpeta '/' (root).
4) Espera unos minutos y abre la URL: https://<tu-usuario>.github.io/<repo>/ desde Safari en tu iPhone.
5) Añade a pantalla de inicio para usarlo como app.

Si quieres que implemente parsing avanzado de mediciones y export CSV, dímelo y lo preparo.
